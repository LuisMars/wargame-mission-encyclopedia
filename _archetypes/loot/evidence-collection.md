<div lang="en" markdown="1">

#### Core
Evidence tokens are placed at multiple sites across the battlefield; collect a complete set of evidence.

#### Win Condition
Complete a full set of evidence.

#### Variants
- Evidence must be catalogued at a home marker before it counts
- Evidence decays over time if not secured
- Different types of evidence are required to complete the set

</div>

<div lang="es" markdown="1">

#### Concepto
Fichas de evidencia están colocadas en múltiples sitios del campo de batalla; reune un conjunto completo de evidencia.

#### Condición de Victoria
Completar un conjunto completo de evidencia.

#### Variantes
- La evidencia debe catalogarse en un marcador base antes de que cuente
- La evidencia se degrada con el tiempo si no se asegura
- Se requieren diferentes tipos de evidencia para completar el conjunto
